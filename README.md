## "家宽"这个词，在 VPS 市场里有三种卖法

先把概念理清楚，否则很容易花冤枉钱。

平台判断一个 IP 干不干净，不只看它属于哪个国家，还看 ASN 和 IP 数据库里的类型标签。机房 IP 在 ipinfo 这类库里被标成 hosting，注册新账号、下单、投广告时就容易触发人机验证；住宅 IP 被标成 ISP，同样的操作顺畅得多。

但"家宽"这个词被用得很松，市面上至少三种东西都叫家宽：

**第一种，机房里的双ISP属性 IP。** IP 段注册在运营商名下，多数 IP 库会识别成 ISP 类型，物理位置仍在数据中心。这是丽萨主机 68元/月 这一档在卖的东西，也是绝大多数人真正需要的。

**第二种，机房里的原生 IP。** 地理定位在美国、注册信息属于美国运营商，但没有 ISP 属性。便宜，适合建站和流媒体，不适合养号。

**第三种，真家宽 VDS。** 硬件直接托管在美国家庭住宅里，走当地宽带运营商的光纤入户，出口就是那条家宽线路。IP 质量最高，代价是价格高、带宽小、基本不做大陆直连优化。

三者的价差大致是：原生 IP 年付折算下来每月十几元，双ISP 68元/月 起步，真家宽 VDS 129元/月起、最高 899元/月。多付的钱买的不是配置，是"被识别为住宅"的深度。跨境电商后台和常规 TikTok 运营，第一种够用；只有当账号单价足够高、封一次号的损失远超一年服务器费用时，第三种才划算。

## 常见问题

**双ISP 和原生 IP 有什么区别？**

原生 IP 指 IP 的注册信息和地理定位属于美国，但类型可能是机房；双ISP 指 IP 在多数数据库里被识别为运营商住宅类型。养号、投流、电商后台认后者，流媒体解锁两者差别不大。

**能装 Windows 吗？**

纽约双ISP 系列和 4837 系列、家宽 VDS 系列支持 Windows；9929 和 CN2 GIA 以 Linux 为主。下单前在配置页确认一下。

**能解锁 Netflix、TikTok、ChatGPT 吗？**

原生 IP 和双ISP 住宅 IP 的套餐都支持解锁 Netflix、Disney+、HBO Max、ESPN、Amazon Prime Video、TikTok、ChatGPT 等美区服务。非原生 IP 的廉价年付套餐解锁能力弱，买之前看清描述。

**IP 被封了怎么办？**

联系客服申请更换，通常 24 小时内处理。整体 IP 质量偏好，触发封禁的概率不高，但没有哪家能保证零封。

**9929 一期和二期有什么差别？**

线路相同，区别在 IP 段和计价策略：一期是双ISP 住宅 IP 段，支持月付；二期是小众美国原生 IP 段，季付及以上更划算。
